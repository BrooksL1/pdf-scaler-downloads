# PDF Scaler (ChatGPT) desktop downloads

Installers for the PDF blueprint and image takeoff app at [pdfo.brooksl.com](https://pdfo.brooksl.com).

## Download version 1.5.1

- [Mac — Apple Silicon (M-series)](https://github.com/BrooksL1/pdf-scaler-downloads/releases/download/v1.5.1/PDF-Scaler-ChatGPT-1.5.1-mac-arm64.dmg)
- [Mac — Intel](https://github.com/BrooksL1/pdf-scaler-downloads/releases/download/v1.5.1/PDF-Scaler-ChatGPT-1.5.1-mac-x64.dmg)
- [Windows — 64-bit installer](https://github.com/BrooksL1/pdf-scaler-downloads/releases/download/v1.5.1/PDF-Scaler-ChatGPT-1.5.1-windows-x64.exe)

On Mac, open the DMG and drag PDF Scaler to Applications. On Windows, run the installer. Save your work before updating an installed app.

These builds are unsigned; Mac builds are not notarized. The Apple Silicon build has been tested on a Mac. Intel Mac and Windows builds have not yet been tested on those target systems.

See the [release notes and checksums](https://github.com/BrooksL1/pdf-scaler-downloads/releases/tag/v1.5.1) for details. The browser version also remains available at [pdf.brooksl.com](https://pdf.brooksl.com).
